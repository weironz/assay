# 平台管理交互与账号模型

## 调研与取舍

- [Microsoft Entra 员工资料](https://learn.microsoft.com/en-us/entra/fundamentals/how-to-manage-user-profile-info)：从员工列表选择用户进入资料详情，身份、工作信息、联系方式分开呈现。本项目沿用列表到详情的路径，补齐工号、部门、岗位与联系方式。
- [authentik 用户组管理](https://docs.goauthentik.io/users-sources/groups/manage_groups)：点击组名进入详情管理成员。本项目将成员移到可搜索、分页的详情列表，用复选框批量添加或移出，不在列表单元格展开全部成员。
- [TrueNAS SMB 管理](https://www.truenas.com/docs/scale/27/shares/smb/addmanagesmbshares/)：共享准入与文件系统 ACL 是不同层次。本项目在目录详情分别展示允许访问的组与 Windows ACL，避免将“能连接共享”误认为“能读写所有内容”。

这些参考用于信息架构；没有引入第三方管理后台或运行时网络依赖。

## 导航与详情

顶部末尾的“文件管理”合并文件访问与管理配置；`/files` 为员工文件入口，`/samba/overview` 为管理概览，按权限展示工作区：

- 文件管理：员工账号 `/samba/users`、用户组 `/samba/groups`、共享目录 `/samba/shares`。
- 账号关联：登录账号关联 `/samba/bindings`。
- 管理审计：目录操作记录 `/samba/history`。

全局平台管理 `/platform` 只管理 Assay 组织架构 `/organization`、系统账号与角色 `/users`。同一文件模块内的可选员工入口“共享文件”位于 `/files`，会话与权限设计见 [员工文件模块](05-员工文件模块.md)。

员工、组、目录均可点击名称进入独立 URL 详情，支持刷新和浏览器前进后退。旧 `/samba` 转向员工列表。列表提供搜索和 20/50/100 条分页；成员和访问组只显示数量，完整列表位于详情页。详情之间可通过员工、组、授权目录名称互相跳转。

员工新增与编辑中的选填字段直接写入 AD 标准属性，不另建员工影子数据库：

| 界面字段 | AD 属性 | 最大字符数 |
| --- | --- | --- |
| 工号 | employeeID | 16 |
| 邮箱 | mail | 254 |
| 部门 | department | 64 |
| 岗位 | title | 64 |
| 电话 | telephoneNumber | 64 |
| 公司 | company | 64 |
| 办公地点 | physicalDeliveryOfficeName | 128 |

旧客户端省略 profile 或属性时保留已有值；明确提交空字符串清除此属性。编辑资料和停用状态使用同一次 LDAP Modify。创建员工仍先建立停用账号，密码与 Unix ID 设置成功后启用。

## 成员操作与删除限制

添加成员使用可搜索复选列表，支持多选、全选搜索结果、清空选择；已在组内的成员不重复列出。移出成员支持逐行或批量操作，不删除员工账号。单次上限 100 名，Agent 先解析并验证全部目标，再一次 LDAP Modify 只增删选中的 member 值，保留其他成员。校验失败不会部分执行。

AD 管理保护对象与不在受管员工 OU 内的成员显示具体原因，不通过任意 DN 参数绕开管理边界。删除用户组前必须移空成员，并从受管共享的访问组中解除引用；按钮旁显示原因。移除共享保留文件和 ACL，详情页支持恢复。

## 当前账号模型

公司 AD 员工账号提供 SMB 身份和文件权限；Assay 登录账号提供 Web 会话与工单、资产等业务角色。默认使用独立本地账号，也可启用 AD 统一登录。完整配置见 [可选 AD 统一登录](06-可选AD统一登录.md)。文件管理中的账号关联通过 AD objectGUID 建立明确对应，用于员工自助修改自己的 AD 密码，以及可选文件模块验证本人的 AD 身份；该文件身份关联本身不复制密码，也不是单点登录开关。平台“身份与访问”中的公司登录关联会明确切换员工的认证来源，详情见上述配置文档。启用 AD 登录后可自动建档并通过组映射授予业务角色。

管理员重置 AD 密码时，第一步填写新的 AD 密码，至少 8 个字符，并由 AD 检查实际复杂度与历史策略；第二步“当前 Assay 登录密码”验证管理员本人。表单与 API 均检查密码长度，参数错误在执行前拒绝。二次验证成功后若操作失败，弹窗区分验证与执行两个阶段，不将所有失败都归为网络错误，也不在弹窗展示原始请求或协议错误。

将来可由 Keycloak/authentik 联接 AD，再通过现有 OIDC 登录 Assay。是否启用这种登录方式是独立配置，不能仅因工号、邮箱相同或某个 AD 组名而自动提升业务权限。

## 本地品牌资源

Logo 已随 Web 镜像打包，以 `/brand/...png` 同源加载，没有 CDN 依赖。此前图片文件为 0600，Nginx 非 root worker 返回 403。生产镜像构建统一静态目录 0755、文件 0644，保证离线内网环境可读取原始品牌图片；浅色与深色图片均保留。
