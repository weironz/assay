## 文件连接跟随 Web 登录（2026-10-15）

## 本地管理员登录恢复与文件关联边界（2026-10-15）

## 已修正的实际问题

1. 连续操作中旧二次验证回调关闭新弹窗：等待整个操作与刷新完成后再关闭，并拒绝旧目录请求覆盖新路径状态。
2. 父目录 ACL 修改不能直接撤销已有文件的继承授权：增加 Rust 的子项继承传播，保留显式/拒绝条目和受保护分支。
3. Samba 会将缺少 AUTO_INHERITED / AUTO_INHERIT_REQ 的继承 ACE 视作显式项：按 Windows 语义同时发送两个标志，并通过真实文件写入验证。
4. 长操作采用异步任务与轮询，接受请求不等于执行成功；重启或超时不确定任务不自动重放。

详细原始测试输出、运行凭据和基线位于执行工作区私有目录，不提交 Git。可复现测试入口为 `deploy/samba-test/tests`。
